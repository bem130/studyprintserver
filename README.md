# StudyPrint Server

Rust web viewer for a StudyPrint index.

## Run

```powershell
cargo run
```

Default paths:

- `STUDYPRINT_INDEX_DIR`: `C:\data\studyprintdata\index`
- `STUDYPRINT_LIBRARY_DIR`: `C:\data\studyprintdata\library`
- `STUDYPRINT_STATIC_DIR`: `static`
- `STUDYPRINT_BIND`: `127.0.0.1:7878`

Open `http://127.0.0.1:7878`.

## Viewer

- Theme toggle switches the UI between light and dark.
- Image tone mode cycles `Auto`, `Invert`, and `Paper`.
- Inverted image mode uses OKLab lightness inversion: paper white becomes dark, black ink becomes light, and pen hue direction is preserved as much as display gamut allows.
- Image tools support rotate, zoom, width/height/page fit, fullscreen, and opening the original PNG.
- Body/XML tabs support fullscreen reading separate from image fullscreen.
- Search and result snippets use XML `altText` for formulas instead of KaTeX-oriented TeX where `altText` is available.
- Prototype viewer state is in-memory only; stale `localStorage` settings are intentionally not used.
- Static viewer assets are served from `STUDYPRINT_STATIC_DIR`; they are not embedded in the Rust binary.
- The frontend source is TypeScript under `frontend/src`; `static/*.js` files are generated by `npm run build:frontend`.
- API response types are generated from Rust DTOs into `frontend/src/generated/api-types.ts`.
